# Infinite Tutorial Logo Assets

This directory contains the official logo assets for Infinite Tutorial:
- `logo-transparent.png` - Full horizontal transparent brand logo
- `logo-emblem-transparent.png` - Transparent 3D emblem mark
- `logo.svg` - Scalable vector logo
- `logo-full.png` / `logo.png` - High-resolution logo masters

Whenever updated assets are provided by the institute, place the new files in this directory or in `frontend/public/`.
